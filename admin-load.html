Admin door. Loads the synthetic EMS cases into the SMART sandbox, then checks every record and link. The sandbox resets every night, so run this before each demo. Running it twice does not create duplicates.

Validation gate: before anything is created, every record is sent to the official HL7 FHIR Validator (FHIR 4.0.1 + US Core 6.1.0). If the validator reports any error, or cannot be reached, nothing is loaded. Synthetic data only: never send real patient data to the public validator.
