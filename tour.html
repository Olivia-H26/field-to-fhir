What the app should do: the goal sentence

Two doors, one sign-in

Both doors use the same SMART sign-in address (one issuer). Each page asks for different permissions.

Door 1: administrator create, read, search

Page: admin-load.html. Signs in as Dr. Albertine Orn, a sample practitioner built into the sandbox, so she is there even after the nightly wipe.
  1. The admin page asks the FHIR server for its SMART settings.
  2. The administrator signs in on the sandbox's sign-in page.
  3. The administrator approves create, read and search permissions (user/....crs), with no update or delete.
  4. The sign-in server gives the admin page a temporary access key for those permissions only.
  5. The admin page sends REST requests: GET to check whether each record exists, then POST to create only the missing ones.

Door 2: EMS provider read and search only

Pages: face page, then dashboard. Signs in as one of the agency's EMTs, who appear on the sandbox sign-in list after door 1 reloads the data.
  1. The face page asks the FHIR server for its SMART settings.
  2. The EMS provider signs in on the sandbox's sign-in page.
  3. The EMS provider approves read and search permissions only (user/....rs).
  4. The sign-in server gives the dashboard a temporary access key, and tells it who signed in (fhirUser).
  5. The dashboard sends GET requests only, such as GET Encounter?participant=…, and shows only that provider's own calls.

The sandbox uses a simplified practice login. In production, each EMT signs in with their own credentials, and the app receives their identity and read-only permissions the same way through SMART.

What the comparison shows

The dashboard compares the EMS and hospital diagnosis codes using the SNOMED CT hierarchy on the HL7 terminology server (FHIR $subsumes).

ResultMeaningExample in the test data
✅ SameThe hospital confirmed the EMS field impression.Sepsis → sepsis
🔵 More specificThe EMS impression was on track; the hospital narrowed it.Myocardial infarction → acute myocardial infarction
🔴 DifferentThe hospital found a different condition.Suspected stroke → low blood sugar (a stroke mimic)
